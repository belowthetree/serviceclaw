## Files Created/Modified

### 1. src/cli/service.ts (NEW - 661 lines)
Implements all 7 CLI commands for service management:

- `serviceclaw service list` - List all installed services with table output
- `serviceclaw service install <path-or-git-url>` - Install from local path or git URL
- `serviceclaw service remove <service-id>` - Remove with confirmation prompt
- `serviceclaw service enable <service-id>` - Enable service processing
- `serviceclaw service disable <service-id>` - Disable service processing
- `serviceclaw service status <service-id>` - Show detailed service status
- `serviceclaw service logs <service-id>` - Show service logs (placeholder)

- JSON output option for list command
- Support for git URL installation with auto-clone
- Support for local path installation
- Config parsing (JSON and key=value format)
- Confirmation prompts for destructive operations
- Comprehensive error handling with actionable messages

## Usage Examples

```bash
# List all services
serviceclaw service list

# Install from local path
serviceclaw service install ./my-service/service.json

# Install from git URL
serviceclaw service install https://github.com/user/service-repo.git

# Enable a service
serviceclaw service enable daily-briefing

# Check status
serviceclaw service status daily-briefing

# Remove a service
serviceclaw service remove daily-briefing --force
```
